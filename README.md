## Research

### TCR α–β pairing compatibility

My current project examines how much information relevant to TCR α–β compatibility is retained in frozen sequence representations. The work centres on experimental design, leakage control, and model capability assessment.

Current work includes:

- sequence and metadata quality control;
- V/J-gene normalization and open-reading-frame checks;
- matched negative sampling and within-individual candidate sets;
- ranking metrics, cross-validation, and residual analysis;
- comparisons with composition-matched decoy β chains;
- remote Linux analysis and reproducible project documentation.

I also contribute computational analysis planning for a National-Level Student Research Training Program involving paired TCR and NGS measurements.
